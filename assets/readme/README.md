# Repository artwork

Original product illustrations generated by [tools/product-visuals](../../tools/product-visuals).
The main overview lives here; the Prep/Chef diagrams are shared with the docs
under `apps/docs/static/demos/`. The original Zeer SVG mark is preserved.

GIFs play once, for approximately 4.8 seconds, then hold their final diagram.
Matching PNGs provide complete static stories and reduced-motion fallbacks.
They explain the data path using verified public sample fields. They are not
fresh execution recordings or performance measurements.

The [asset manifest](manifest.json) records dimensions, hashes and verification.
The finished [1:55 product demo](https://github.com/EndPx/zeer/releases/tag/showcase-20261023)
is a separate release download so the main Git checkout does not carry the MP4.
Working narration, screenshots and intermediate renders remain local.

Original Zeer artwork and source use the repository's MIT license. The font
packages retain their OFL licenses; no font binary is redistributed in this folder.
