# Prep examples

Choose a preset in [Prep Playground](https://zeer.endpx.cloud/app/prep), then select **Run query**. **Use verified testnet sample** fills known inputs without substituting a response.

| Preset | Query focus |
| --- | --- |
| Block history | Headers without transaction bodies |
| Find a transaction | Transaction-ID filtering |
| Payments to an address | Transparent output matching |
| Sapling / Orchard / Ironwood activity | Public pool components |
| Transaction sizes & inputs | Compact size and count fields |
| Filter by version | Public format versions |
| Raw transaction bytes | Serialized transaction hex |

For copyable HTTP requests, use [cURL examples](/docs/prep/curl/).

For scripts with setup, execution and result interpretation, follow [Analyzing Address Outputs](/docs/prep/tutorials/address-outputs/) or [Inspecting Transactions](/docs/prep/tutorials/inspect-transaction/).
