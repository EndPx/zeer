# Build with Zeer

Zeer provides public Zcash data through **Prep** and application indexing through **Chef**.

| Product | Use it to | Start |
| --- | --- | --- |
| Prep | Query blocks and public transactions | [Quickstart](/docs/prep/quickstart/) · [With AI](/docs/prep/quickstart-ai/) |
| Chef | Build entities with TypeScript and query them through GraphQL | [Quickstart](/docs/chef/quickstart/) · [With AI](/docs/chef/quickstart-ai/) |

Try queries in the [playground](https://zeer.endpx.cloud/app), or read [how the layers fit together](/docs/architecture/).

**Notes:** The hosted preview uses Zcash testnet. Authorized shielded receipts and memos are available through [Chef's local setup](/docs/chef/shielded/local/).
